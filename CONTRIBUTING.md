# Contribuir

Gracias por querer contribuir a este proyecto. Sigue estos pasos para que tus cambios sean fáciles de revisar:

1. Fork o crea una rama desde `feature/project-restructure` para trabajo en curso:
   - `git checkout -b feature/descripcion-corta`
2. Mantén commits pequeños y con mensajes claros (en español):
   - `git add .`
   - `git commit -m "feat: añadir X"`
3. Ejecuta linters y pruebas antes de push (si aplicable):
   - `npm run lint`
   - `npm run test`
4. Abre un Pull Request hacia `feature/project-restructure` describiendo:
   - Qué se cambió
   - Por qué
   - Cómo probarlo localmente

Para cambios grandes, abre un issue primero para discutir el diseño.
